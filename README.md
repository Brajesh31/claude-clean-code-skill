# Clean Code

Pragmatic coding standards that prioritize clarity, direct solutions, and maintainable implementation without unnecessary complexity.

## Core principles

- Keep functions and classes focused on a single responsibility.
- Avoid duplication while preserving clear abstractions.
- Prefer simple, readable implementations over speculative frameworks.
- Remove dead code and unnecessary indirection.
- Use comments only when they explain intent or non-obvious constraints.
- Make changes proportionate to the requested task.

## Usage

Use this skill when writing, reviewing, or refactoring code. Apply the standards to the relevant scope, preserve existing project conventions, and avoid unrelated rewrites.

The goal is not minimum line count. The goal is code that another developer can understand, test, and change safely.
